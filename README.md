# BIG CANNA AgriHub — GitHub Pages starter

A responsive, static landing page for BIG CANNA, an agricultural initiative under Donum Mod Consulting.

## Files
- `index.html` — page structure and copy
- `styles.css` — responsive design, palette, cards, typography and layouts
- `script.js` — mobile navigation, current year and enquiry email draft
- `assets/big-canna-logo.svg` — combined canna flower + geometric green leaf logo
- `assets/big-canna-logo-light.svg` — light footer version
- `assets/canna-mark.svg` — standalone mark for favicon
- `assets/canna-botanical.svg` — botanical illustration used in the Canna Principle section

## Preview locally
Open `index.html` in a browser. An internet connection is needed for the remote Unsplash photography.

## Publish on GitHub Pages
1. Create a repository such as `big-canna-agrihub`.
2. Upload the contents of this folder (the `index.html` must be at repository root).
3. In GitHub, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the Pages deployment and open the generated URL.

## Before publishing
- Replace the placeholder `hello@donummod.co.za` in `script.js` with the real contact inbox. The contact form opens an email draft; it does not store submissions. For direct web submissions, connect a form backend such as Formspree or Netlify Forms.
- Confirm the correct parent-company link, social links, and contact details.
- Replace illustrative project cards with current, verified BIG CANNA activities as they become available.
- The canna plant's possible uses vary by species/cultivar and context. Avoid implying that every application is already a BIG CANNA product or commercial offering.
- All photos are loaded from Unsplash URLs, so the deployed page requires internet access. For a fully self-contained/offline site, download licensed images into `assets/` and update their paths.
- The logo and botanical SVGs are editable vector artwork; adjust colors in the SVG files to tune the brand.
